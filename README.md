# Crossword Heist
Node 20+; npm install; npm test; npm start. Render: Node web service, build npm install, start npm start, health /health. Upload contents to GitHub. No API keys.
Shared 15x15 crossword, 15–20 connected answers, 650 authored clue pairs in clues.txt (only 4–10 letter answers used). Choose a clue, type answer, claim, attack or guard. Same lobby combat, teams, skip, rematch and cumulative points as Word Heist. Solutions remain server-side until claimed or revealed. Each lobby avoids repeating answer sets across rematches; memory resets when lobby closes or server restarts. Different lobbies may repeat. Clues are authored, not externally verified; synonyms may not match the intended answer. Mobile layout uses compact board and native keyboard; physical device and live multiplayer testing outstanding. Automated tests validate crossword structure and combat calculations, not clue quality or UI.

Version 1.1: larger board, amber theme, mobile scrolling, 650 unique clue-answer pairs. Clues are AI-authored and not independently reviewed.
